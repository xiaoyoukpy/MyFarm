# 我的农场（My Farm）

一款**笔记本风格**的农场经营模拟游戏。你从老农场主手中继承了一片农场，在这本笔记本上规划每一天：安排计划、种植作物、建造建筑、应对天气与季节，经营出属于自己的理想农场。

## 快速开始

1. 直接用浏览器打开 `index.html`（推荐 Chrome / Edge）
2. 点击「开始游戏」选择一个存档位，即可开始经营

> 游戏进度自动保存在浏览器 `localStorage` 中，支持 3 个存档位，可随时覆盖、删除。

## 游戏玩法

### 核心循环

点击底部的「📖 翻到下一页」推进一天，自动结算：

```
翻页 → 种下待种作物 → 执行计划 → 建筑收入 → 作物生长 → 生成天气 → 随机事件 → 信件触发
```

### 区域总览

| 区域 | 功能 |
|------|------|
| 📬 通讯 | 接收引导信件、老农场主来信、合作商人收购订单 |
| 🌾 农场情况 | 查看天气、季节、作物生长进度、建筑列表、今日小结 |
| 📦 农场仓库 | 存放收获的作物、蛋、鱼与加工品，按种类堆叠，选择数量出售 |
| 🐔 鸡舍 | 管理母鸡，购买母鸡、查看蛋类产出 |
| 📋 计划项目 | 种植作物、建造/升级建筑、购买田地/扩容计划/买地，同时最多进行 **5** 个计划 |
| 🏪 下一区域（小镇） | 第 31 天起解锁，含加工坊、娱乐厅、码头、熟食间、银行（详见下文） |
| 📊 日志 | 每日收支、收获次数与事件记录 |
| 📖 图鉴 | 作物/养殖产物/建筑/鱼的收集进度与统计 |
| 🛒 商店 | 复种作物解锁、神秘种子、扩容计划、买地 |

### 作物系统

- 点击「种植」后作物**第二天开始生长**，成熟后点击「收获」存入仓库
- 种植位占用田地容量，待种植的种子也计入容量；种不下就先造田地 / 买地

| 作物 | 生长 | 基础售价 | 种子 |
|------|------|------|------|
| 胡萝卜 | 3天 | 30 | 10 |
| 玉米 | 4天 | 40 | 15 |
| 番茄 | 5天 | 50 | 20 |
| 卷心菜 | 5天 | 45 | 20 |
| 土豆 | 6天 | 60 | 25 |
| 南瓜 | 7天 | 90 | 45 |

### 复种作物（金币解锁）

花费金币解锁永久可种的高级作物，收获后**植株保留**，每隔几天自动重新结果，无需再次购买种子：

| 作物 | 解锁费 | 首次生长 | 再生 | 每次售价 | 种子 |
|------|------|------|------|------|------|
| 🍓 草莓 | 150 | 4天 | 2天 | 20 | 40 |
| 🌶️ 辣椒 | 250 | 5天 | 2天 | 25 | 50 |
| 🫐 蓝莓 | 350 | 5天 | 2天 | 30 | 60 |

在「🛒 商店」中点击「解锁」即可，长期收益远超普通作物。

### 鸡舍系统

「🐔 鸡舍」页管理你的母鸡：

1. 在「📋 计划项目」中建造**鸡舍**（80金币，每座容纳 5 只母鸡）
2. 在「鸡舍」页购买母鸡（50金币/只）
3. 每只母鸡每天有 **60%** 概率产蛋，蛋有 **10%** 概率是大鸡蛋（售价高 50%）
4. 产出的蛋自动存入仓库，像作物一样出售

仓库支持**一键出售全部**（带二次确认和价格预览）。

| 产品 | 基础售价 |
|------|------|
| 🥚 鸡蛋 | 15 |
| 🥚 大鸡蛋 | 22 |

### 合作商人

「📬 通讯」页会不定期收到合作商人的**高价收购订单**（如"收购玉米×8，单价64金币"）：

- 收购价比市价高 40%~70%，且不受季节波动影响
- 订单限时 5 天，仓库备足货后一键出售
- 同一时间最多 2 个订单，每天有概率刷新

### 图鉴

「📖 图鉴」页记录你的农场足迹：

- **作物图鉴 / 鱼图鉴**：解锁状态、生长与售价数据、累计收获与出售统计
- **建筑图鉴**：建造数量与最高等级
- 未解锁/未建造的内容以"？？？"形式保密

### 仓库与出售

- 收获的作物、蛋、**鱼及加工品**先入仓库，不急着卖——看准时机再出手
- 仓库中同类物品自动堆叠（如 `胡萝卜 × 5`），并实时显示单价与合计价值
- 出售时可**选择数量**（支持全部出售），实时预览总价；单条鱼也可单独出售
- 实际售价 = 基础售价 × 季节加成 × 谷仓加成 × 娱乐厅加成 × 当日事件加成
- 经营提示：冬季售价最高，市集促销日（+20%）出手最划算

### 计划项目与田地

- 同时最多进行 **5** 个计划（初始 3 个，可在「🛒 商店」用「扩容计划」+2 个，分别花费 5000 / 10000 金币）
- 田地基础容量上限 **10** 块，可在「🛒 商店」用「买地」扩充：每块 **25000** 金币，田地上限 +1（可叠加）

### 建筑系统（基础区）

| 建筑 | 造价 | 效果 |
|------|------|------|
| 田地 | 50 | 提供种植位，Lv1~Lv3 分别可种 **2/3/4** 个作物 |
| 谷仓 | 100 | 提升售价，最多 **3 座**，每座 **+8%/+16%/+20%**，可叠加 |
| 鸡舍 | 80 | 每天产出金币 **15/20/25**（按等级） |
| 水井 | 60 | 缩短成熟时间，最多 **2 座**，每座 **-5%/-10%/-15%**，可叠加 |
| 收割机 | 2000起 | 作物成熟后**自动收割**并存入仓库；无购买上限，成本随拥有数递增（×1.5ⁿ），每座每天最多自动收割 **16** 个作物，可多座叠加 |

### 四季系统

每 **30 天**为一季，循环往复。季节影响生长时间和售价：

| 季节 | 生长时间 | 售价 |
|------|---------|------|
| 春 | ×0.8（最快） | ×0.8 |
| 夏 | ×1.0 | ×0.7（最低） |
| 秋 | ×1.2 | ×1.2 |
| 冬 | ×1.5（最慢） | ×1.5（最高） |

> 经营思路：春季快速周转冲量，冬季囤货卖高价。

### 天气与事件

- 每天随机天气：☀️ 晴 50% / 🌧️ 雨 25% / ☁️ 阴 15%（❄️ 雪 仅在冬季出现）
- 雪天会使所有生长中作物延迟 1 天，并有概率冻死一株作物
- 每天 10% 概率触发随机事件（市集促销、暴风雨、害虫、旅行商人等）

### 商店

左侧「🛒 商店」页提供：

- **种子解锁**：花费金币永久解锁复种作物（草莓、辣椒、蓝莓），解锁后即可在「计划项目 → 种植作物」中种植。
- **神秘种子**：花费 `100` 金币购买，每月限购 `3` 次。购买后种子进入仓库，在仓库中点「种植」（田地有余量时）即可种下，5 天后收获随机获得：5% 未兑奖的彩票、5% 农场奖杯、90% 随机作物。彩票（售价 100000）与奖杯（售价 1000）会进入仓库，并在「图鉴 → 其他」中显示收集进度（获得前显示「？」）。
- **扩容计划**：花费 5000 / 10000 金币，计划槽位 3 → 5。
- **买地**：每块 25000 金币，田地上限 +1。

### 老农场主的信

每 30 天，老农场主会检查你这一季的营收与行为，寄来一封信：

- **什么都没做** → 一封沉默的信
- **营收 ≥ 2500** → 震惊的信
- **营收 ≥ 500** → 夸赞的信
- **有动作但收入不佳** → 鼓励的信

第一个月理论最优收益约 **2680 金币**，你能做到吗？

## 下一区域（小镇）

第 **31 天**起可在「📋 计划项目」支付 **45000** 金币开通新区「小镇」，右侧出现「🏪 下一区域」入口。内含以下设施（升级上限均为 Lv3，但当前版本暂未开放升级效果，仅建造使用）：

| 设施 | 造价 | 功能 |
|------|------|------|
| 🏭 加工坊 | 20000 | 作物 → 高价制品；鱼去磷；需每月缴 2500 维护费 |
| 🎡 娱乐厅 | 15000 | 幸运轮盘赌博 |
| ⚓ 码头 | 30000 | 雇佣工人钓鱼 |
| 🍱 熟食间 | 25000 | 需先有加工坊；去磷鱼 → 熟鱼 |
| 🏦 银行 | 15000 | 活期存款，日息结算 |

### 加工坊

- **加工**：把仓库里的作物加工成更高价的制品（苹果→苹果酱、土豆→土豆泥、玉米→玉米罐头、葡萄→葡萄酒……共 14 种配方），耗时 2 天。
- **去磷**：把生鱼（鱼_生_×）去磷为去磷鱼，耗时 1 天，售价约为生鱼的 0.8 倍。
- **一键加工（含去磷）**：一次把仓库里所有可加工的作物与所有可去磷的生鱼批量提交任务。
- **维护费**：每月 **2500** 金币；欠费时加工坊停用，需手动补缴后才能继续加工。

### 娱乐厅（幸运轮盘）

押注红 / 黑 / 绿三色：

- 红 / 黑：中奖本金 **×2**
- 绿：中奖本金 **×20**
- 猜错：本金清零

### 码头（钓鱼）

- 建造后可在「钓鱼」页**雇佣工人**（最多 **10** 人，免费雇佣），每名工人每天钓 **2 条鱼**、日薪 **400** 金币。
- 每日结算时若金币不足以支付全部工资，工人**罢工**（当天不钓鱼、不扣款），补够金币后次日自动复工。
- 鱼共 **10 种**：

| 鱼 | 生鱼价 | 去磷鱼价 | 熟鱼价 |
|----|-------|---------|-------|
| 鲤鱼 | 100 | 80 | 200 |
| 草鱼 | 120 | 96 | 240 |
| 鲫鱼 | 130 | 104 | 260 |
| 鲈鱼 | 150 | 120 | 300 |
| 带鱼 | 160 | 128 | 320 |
| 鲅鱼 | 180 | 144 | 360 |
| 黄花鱼 | 200 | 160 | 400 |
| 鲳鱼 | 220 | 176 | 440 |
| 鳕鱼 | 250 | 200 | 500 |
| 金龙鱼（稀有，1%） | 50000 | 40000 | 100000 |

> 价格关系：**熟鱼 = 2 × 生鱼**；**去磷鱼 ≈ 0.8 × 生鱼**。「港口」区暂未开放。

### 熟食间

- 需先拥有**加工坊**才能建造。
- 把加工坊去磷后的鱼，花 **1 天**制成「熟鱼」，售价为生鱼的 **2 倍**。
- **一键烹饪**：一次把仓库里全部去磷鱼批量提交烹饪任务。

### 银行

- 建造后可**存入**金币，按 **0.05% / 天** 日息每日结算利息，随时**取出**本金与利息。
- 提供「全部存入」「全部取出」快捷按钮。
- 利息在每日翻页时结算，存入金额越多、时间越久收益越高（适合资金闲置期理财）。

## 项目结构

```
我的农场/
├── index.html              # 页面骨架
├── css/
│   ├── base.css            # CSS 变量、样式重置
│   ├── notebook.css        # 笔记本外观（纸张纹理、阴影）
│   ├── layout.css          # 三栏布局、响应式
│   ├── components.css      # 卡片、按钮、模态框等组件
│   ├── animations.css      # 翻页动画、过渡效果
│   ├── menu.css            # 主菜单、存档选择
│   └── icons.css           # 纯 CSS 图标（天气/作物/建筑）
├── js/
│   ├── data.js             # 配置常量、作物/建筑/季节/信件/鱼 数据
│   ├── storage.js          # StorageManager，localStorage 三存档位
│   ├── game.js             # Game 类：翻页结算、季节、仓库、信件、收益、新区
│   ├── ui.js               # UIManager：渲染、仓库出售、模态框、小镇界面
│   └── main.js             # 入口：初始化与事件绑定
└── 开发文档.md              # 开发文档
```

## 技术说明

- **零依赖**：原生 HTML5 + CSS3 + JavaScript (ES6+)，所有图标均为纯 CSS 绘制
- **数据持久化**：`localStorage` 自动保存/读取，键名 `myFarmData_slot{1,2,3}`，含存档元信息
- **存档兼容**：加载旧存档时自动迁移补齐新字段（初始田地建筑化、仓库、新区状态等）
- **推荐分辨率**：1280px 以上桌面屏幕
